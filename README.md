# Route Lens U.S. map data

This branch contains a processed U.S. extract from [Geofabrik](https://download.geofabrik.de/north-america/us/). The manifest records the snapshot timestamp and coverage. The binary files are concatenated gzip records. Their JSON index files map geographic cells to byte offsets and lengths.
